# taskcomm

_Что здесь: витрина проекта. Читатель за минуту понимает, что это, нужно ли ему, и куда идти
дальше. Подробностей нет — только ссылки на руководство._

## Что это

_Абзац из architecture.md, раздел 1: стартер Spring Boot для фоновых задач с подзадачами
и коммуникаций с внешними системами — на PostgreSQL, без брокера и без отдельного сервиса._

## Когда он нужен

_Три-четыре типовых сценария одной строкой: массовая обработка с повтором по одному объекту,
интеграция с внешней системой с повторами и размыкателем, приём вебхуков, отложенный запуск._

## Возможности

_Короткий список: три контракта задач, раскрытие и сборка, коммуникации по транспортам,
дедупликация и корреляция, повторы и аренда, горизонтальное масштабирование, REST, метрики._

## Чем отличается от аналогов

_Таблица против Quartz, JobRunr, db-scheduler, Spring Batch, outbox-библиотек: что есть у нас
и чего нет у них, и честно — чего нет у нас (раздел «Чего проект не делает» из architecture.md)._

## Пример за минуту

_Зависимость, один процессор, один вызов `submit` — без пояснений, со ссылкой на быстрый старт._

## Требования

_Java 25, Spring Boot 4.1, PostgreSQL — с версиями. Подробно — в быстром старте._
