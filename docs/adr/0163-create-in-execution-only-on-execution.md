# 0163. «Создать в этом деле» — только на экране дела

- **Дата:** 2026-11-13
- **Статус:** принято

## Контекст

[0153](0153-ui-creation-refinements.md) поставил кнопку «Создать в этом деле» на экран дела
и на карточки задачи и коммуникации. На карточках она стоит среди действий над самой сущностью —
отмены и перезапуска, — хотя к сущности отношения не имеет: создаёт новую работу в деле.

## Решение

- Кнопка «Создать в этом деле» — **только на экране дела**. На карточках задачи и коммуникации
  её нет: с карточки в дело ведёт ссылка в описании, а поле дела в форме создания принимает
  и один идентификатор ([0153](0153-ui-creation-refinements.md)).

## Рассмотренные варианты

- **Оставить на карточках.** Отвергнуто: строка действий карточки — про саму сущность, а кнопка
  создаёт другую.

## Последствия

- Чтобы поставить работу в дело карточки, — переход на экран дела по ссылке, либо идентификатор
  дела в форме создания.
