# 0154. Оболочка интерфейса: заголовок из настроек, экземпляр в `/meta`, тёмная тема по умолчанию

- **Дата:** 2026-11-12
- **Статус:** принято

## Контекст

Интерфейс ([0149](0149-web-interface-module.md)) живёт внутри чужих приложений, и на нескольких
стендах сразу. Человеку нужно видеть, **в какое приложение** он смотрит и **какой экземпляр** ему
ответил: размыкатели, обмен и опрос идут через тот экземпляр, на который попал запрос. Заголовок
в шапке был жёстко «taskcomm», а имени экземпляра в `/meta` нет —
[0150](0150-execution-outline-and-meta.md) счёл его внутренним делом движков.

Тема бралась из настройки системы; переключить её из интерфейса было нельзя.

## Рассмотренные варианты

### Заголовок

- **Из `spring.application.name`.** Не у всех задано, и стартер начал бы читать чужое свойство
  ради надписи. Отвергнуто.
- **Своё свойство `taskcomm.ui.title`, по умолчанию `taskcomm` — выбрано.** Контроллер интерфейса
  вставляет его в `index.html` вместе с путями: в `<title>` вкладки и в `<meta name="taskcomm-title">`
  для шапки. Отдельного запроса не нужно, и заголовок виден до ответа REST.

### Экземпляр

- **Через API чтения.** Имя экземпляра — не данные подсистем, и ради строки расширять два
  публичных интерфейса незачем. Отвергнуто.
- **В `/meta`, тем же выражением, что у движков — выбрано:** имя JVM
  (`RuntimeMXBean.getName()`, обычно `pid@host`). Оно же стоит в `locked_by` попыток и в выдаче
  размыкателей, так что интерфейс показывает ровно то, что человек найдёт в истории попыток.
  Изменяет решение [0150](0150-execution-outline-and-meta.md) «имени экземпляра в `meta` нет».

### Тема

- **По настройке системы, без переключателя.** Отвергнуто: нужен явный выбор.
- **Переключатель светлая/тёмная, по умолчанию тёмная, выбор помнится в браузере — выбрано.**

## Решение

- `taskcomm.ui.title` — по умолчанию `taskcomm`; вставляется в `<title>` и `<meta name="taskcomm-title">`,
  с экранированием HTML.
- `/meta` отдаёт `instance` — имя JVM ответившего экземпляра.
- Тема — тёмная по умолчанию, переключатель в подвале рядом с языком, версией и экземпляром.

## Последствия

- Выражение имени экземпляра повторено в REST третьим местом — рядом с двумя движками. Разойтись
  они могут только при правке одного из трёх, и это надо помнить.
- Свойство `taskcomm.ui.title` видно в автодополнении и без модуля, как и остальные `taskcomm.ui.*`
  ([0149](0149-web-interface-module.md)).

## Связанные решения

- [0150](0150-execution-outline-and-meta.md) — `/meta`; здесь в неё добавлен экземпляр.
- [0152](0152-web-interface-frontend-stack.md) — тема была по системе; здесь — переключатель.
