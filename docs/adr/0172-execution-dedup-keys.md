# 0172. Ключи дедупликации дела

- **Дата:** 2026-11-17
- **Статус:** принято

## Контекст

На экране дела есть вкладка ключей корреляции всего дела: выдача дела отдаёт их из
`CommunicationInspection.correlationKeys(ExecutionRef)` ([0150](0150-execution-outline-and-meta.md)).
Ключи дедупликации видны только в карточке одной коммуникации, и чтобы понять, какие ключи заняло
дело, приходится открывать коммуникации по одной.

В отличие от реестра корреляции, в строке ключа дедупликации дела нет
([0076](0076-communication-deduplication.md)): ключ принадлежит коммуникации, а её дело — в строке
коммуникации. Обе таблицы — в партиции дела.

## Рассмотренные варианты

- **Собирать на клиенте по карточкам коммуникаций.** Запрос на каждую коммуникацию дела и все —
  при каждом опросе. Отвергнуто, как и в [0166](0166-execution-outline-units-and-attempts.md).
- **Колонка дела в таблице ключей.** Чтение по ней проще, но это миграция схемы и запись лишнего
  значения при каждой регистрации ключа ради экрана. Отвергнуто.
- **Чтение через коммуникации дела — выбрано:** соединение ключей с коммуникациями в партиции дела,
  коммуникации — по индексу дела.

## Решение

- `CommunicationInspection.dedupKeys(ExecutionRef)` → `List<DedupKeyEntry>` в порядке регистрации
  и `dedupKeysSql(ExecutionRef)` ([0165](0165-read-sql.md)), оба `default` с
  `UnsupportedOperationException`. Запись `DedupKeyEntry`: направление и система — пространство
  ключа, предмет, значение, коммуникация, время регистрации.
- В выдаче дела целиком и без подзадач — `dedupKeys`; в SQL выдачи без подзадач — запрос
  «Ключи дедупликации дела».
- На экране дела — вкладка «Ключи дедупликации» рядом с ключами корреляции: направление, система,
  предмет, ключ — ссылкой на поиск в его пространстве, как в карточке, — коммуникация, время.
  Сервер без поля — вкладки нет.

## Последствия

- Поверхность публичного API растёт на запись и два `default`-метода; аддитивно.
- Индекса по коммуникации у таблицы ключей нет — как и у чтения ключей одной коммуникации. Соединение
  обходит ключи партиции дела; партиция — не всё хранилище, и это чтение экрана, не горячий путь.
- Выдача дела тяжелее на ключи дедупликации его коммуникаций — их обычно не больше, чем коммуникаций.
