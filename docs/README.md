# Документация taskcomm

Здесь документы для двух разных читателей.

## Если вы подключаете стартер

[Руководство](guide/README.md) — всё, что нужно приложению, которое использует taskcomm:
по разделам — от быстрого старта до эксплуатации, с примерами в каждом разделе.

Обязательно прочитайте [Совместимость](guide/evolution/compatibility.md) — что нельзя менять в своём коде,
когда задачи уже лежат в базе.

## Если вы разрабатываете стартер

- [rules/](rules/) — правила разработки по темам; приоритет у них тот же, что у CLAUDE.md.
- [Журнал решений](adr/README.md) — каждое архитектурное решение с отвергнутыми вариантами.
- [roadmap.md](roadmap.md) — что сделано и что дальше.
- [CLAUDE.md](../CLAUDE.md) — ядро правил: стек, структура, стиль, команды.
