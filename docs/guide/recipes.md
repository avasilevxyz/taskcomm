# Рецепты

_Что здесь: сквозные кейсы с кодом от постановки до результата. Каждый рецепт: задача, решение, код, на что обратить внимание._

## Массовая обработка списка

_задача с подзадачами: обработать тысячу объектов, повтор по одному, сборка итога._

## Обработка партиями

_задача с группами: партии по N объектов с общими параметрами._

## Отложенное действие

_напоминание через сутки с отменой, если стало не нужно._

## Вызов внешнего REST с повторами

_исходящая коммуникация, отказные статусы, размыкатель._

## Задача, которая зовёт внешнюю систему

_процессор задачи отправляет коммуникацию в своём деле._

## Приём вебхука

_асинхронный приём из контроллера и обработка процессором входящей._

## Синхронный обмен с ответом отправителю

_receiveAndProcess и ответ процессора._

## Отправка и ожидание колбэка

_исходящая с корреляцией и обработка асинхронного ответа._

## Защита от дублей

_дедупликация повторной отправки и повторного приёма._

## Миграция контракта процессора

_новый тип задачи вместо правки старого: шаги и проверка по метрикам._
