# Осиротевшие задачи и коммуникации

**Осиротевшая** — незавершённая работа типа задачи или внешней системы, для которой в приложении
нет процессора. Так бывает, если процессор удалили, переименовали тип или систему, или выкатили
версию без процессора.

Такая работа **не берётся и не меняет состояния** — она стоит в `PENDING` и поедет сама, как только
процессор вернётся. Видна тремя способами: предупреждением при старте, метрикой
`tc.*.orphaned` и признаком `orphan` в REST и API чтения.

Что делать:

- **процессор пропал по ошибке** — верните его, работа доделается;
- **тип переименовали** — верните процессор под старым именем, помеченный `@Deprecated`,
  и дайте ему доработать: тип задачи — ключ данных, см. [Совместимость](../evolution/compatibility.md);
- **работа не нужна** — отмените её.

Осиротевшая работа держит свою партицию от удаления — дольше ждать не значит безопаснее.
