# Руководство потребителя

_Что здесь: оглавление и карта по ролям. Кто вы — тот, кто ставит задачи, пишет процессоры, интегрирует внешнюю систему или сопровождает, — и в каком порядке читать._

## Как читать

_порядок: быстрый старт → понятия → задачи или коммуникации → настройки; остальное — по необходимости._

## Карта по ролям

_таблица «я хочу… — читай…»: поставить задачу, написать процессор, принять вебхук, настроить повторы, включить REST, завести метрики, обновить версию._
