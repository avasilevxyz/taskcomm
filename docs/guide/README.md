# Руководство

Руководство для тех, кто подключает taskcomm к своему приложению: как ставить задачи, писать
процессоры, обмениваться с внешними системами и сопровождать всё это в работе.

## Как читать

1. [Быстрый старт](start/quick-start.md) — подключить, применить схему, выполнить первую задачу.
2. [Понятия](start/concepts.md) — словарь: без него остальные страницы читаются с трудом.
3. [Задачи](tasks/README.md) или [Коммуникации](communications/README.md) — смотря что вам нужно.
4. [Совместимость](evolution/compatibility.md) — **до первого релиза**: что в вашем коде нельзя
   менять, когда задачи уже лежат в базе.

Остальное — по необходимости, по разделам и карте ниже. У каждого раздела своя страница
с перечнем статей и примеров.

## Чего нельзя менять в своём коде

Задачи и коммуникации живут в базе дольше, чем один релиз вашего приложения. Тип задачи, имя
внешней системы, контракт процессора, поля класса нагрузки — это формат уже записанных данных,
и часть их изменений ломает данные **молча**. Прочитайте [Совместимость](evolution/compatibility.md)
до первого релиза и перед любой правкой процессора, типа или имени системы.
