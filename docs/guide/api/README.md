# Управление и чтение

Как читать задачи, коммуникации и дела, искать по нагрузке, отменять и перезапускать — из своего
кода или по HTTP. REST-контроллеры стартера построены поверх Java API, поэтому возможности у них
одни и те же; различаются вход и безопасность.

| Страница                  | О чём                                                                  |
|---------------------------|------------------------------------------------------------------------|
| [Чтение из кода](java.md) | Java API: запросы, снимки, поиск по нагрузке, сводки, отмена по снимку |
| [REST API](rest.md)       | Включение, безопасность, эндпоинты, окно поиска, ошибки                |

Что означают отмена и перезапуск на каждом уровне — в [Задачах](../tasks/cancel-restart.md)
и [Коммуникациях](../communications/cancel-restart.md).
