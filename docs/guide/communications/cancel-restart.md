# Отмена и перезапуск

```java
CommunicationCancelResult cancel = communicationService.cancel(communication);
CommunicationRestartResult restart = communicationService.restart(communication);
```

Перегрузки — по коммуникации и по снимку из [API чтения](../api/java.md); результат — `Accepted`
или `Rejected` с причиной.

- **Отмена**: ждущая отправки или ответа становится `CANCELLED` сразу; работающая доигрывает
  и пишет настоящий исход. Терминальная не отменяется.
- **Перезапуск** — только `FAILED` и не отменённой. Всегда с отправки или обработки: исходящая
  отправится заново, даже если упала только обработка ответа; входящая обработается заново
  с тем же запросом. Входящая с неразобранным телом не перезапускается.

Ручной перезапуск синхронно принятой входящей обработает её в фоне — ответ сохранится, но
отправителю его уже никто не отдаст.
