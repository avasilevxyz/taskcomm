# Постановка задачи

`TaskService.submit` — по классу процессора или по строке типа:

```java
Task<SyncPeriod> task = taskService.submit(OrderSyncProcessor.class, new SyncPeriod(from, to));
Task<SyncPeriod> same = taskService.submit("order-sync", new SyncPeriod(from, to));
```

По классу надёжнее: компилятор проверит тип нагрузки, а переименование типа не сломает вызов.
Постановка по типу, для которого нет процессора, бросает исключение — опечатка в имени не станет
тихо зависшей задачей. Процессор помечен `@Deprecated` — постановка тоже отвергается, см.
[Совместимость](../evolution/compatibility.md).

Редкие сочетания — через `TaskSubmitOptions`:

```java
taskService.submit(OrderSyncProcessor.class, period, TaskSubmitOptions.defaults()
        .priority(10)                          // меньше — важнее
        .notBefore(Instant.parse("2026-12-01T03:00:00Z"))
        .inNewExecution());                    // не наследовать дело процессора
```

| Опция                | Что делает                                                  |
|----------------------|-------------------------------------------------------------|
| `inExecution(ref)`   | Положить задачу в указанное дело                            |
| `inNewExecution()`   | Завести новое дело, даже если ставите из процессора         |
| `priority(n)`        | Приоритет этой задачи вместо значения по умолчанию для типа |
| `notBefore(instant)` | Не начинать раньше указанного момента                       |

Перегрузка `submit(type, payload, executionRef)` — короткая форма для `inExecution`.

**Транзакция.** Постановка пишется в вашу текущую транзакцию: задача видна воркеру с момента
коммита и исчезает при откате. Вне транзакции — например, из процессора — стартер открывает свою
короткую. Ставить задачу из транзакции на **другой** базе нельзя — исключение, а не тихое
расхождение. Подробно — [Встраивание](../setup/database.md#база-и-транзакции).

**Из JSON.** `submitJson(type, json, options)` — для кода без доменной формы нагрузки, например
админки. JSON разбирается в тип нагрузки процессора сразу, до записи; не разобрался —
`UnreadablePayloadException`.

**Найти поставленные.** `findInExecution(execution, type)` — задачи указанного типа в деле,
в порядке создания.
