# Несколько экземпляров

Экземпляры делят работу через базу и ничего не знают друг о друге — настраивать ничего не нужно.

| Что                               | Кто делает                                        |
|-----------------------------------|---------------------------------------------------|
| Захват и выполнение работы        | Все экземпляры, каждый свою долю (`SKIP LOCKED`)  |
| Heartbeat                         | Каждый — для своих попыток                        |
| Переподхват истёкшей аренды       | Любой, кто первым заметит                         |
| Обслуживание партиций             | Один за такт — взявший блокировку                 |
| Подсчёт метрик очереди            | Один за такт; публикуют все одно и то же значение |
| Ограничение скорости, размыкатель | Каждый сам по себе                                |

Отсюда две вещи для эксплуатации: метрики очереди складывайте по экземплярам `max()`, а не
`sum()`; лимит скорости внешней системы делите на число экземпляров.
